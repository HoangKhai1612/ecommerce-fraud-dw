ISSUES ENCOUNTERED
------------------
1. PostgreSQL schema concatenation: dbt's default `default__generate_schema_name` 
   macro concatenates target schema with custom schema (e.g., "raw" + "staging" = "raw_staging").
   Solution: Created macros/schema_override.sql to override the macro and use 
   custom schema name directly.

2. protobuf compatibility: dbt 1.8.0 installed with protobuf 4.25.x which is 
   incompatible with Python 3.14 (TypeError: Metaclasses with custom tp_new 
   are not supported). Fixed by upgrading protobuf to 7.36.1.
